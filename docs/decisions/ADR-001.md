# ADR-001 · 저장과 배포 구현 결정

| 결정 | 구현 및 적용 이유 |
|---|---|
| 브라우저 영속성 | IndexedDB 워크스페이스 스냅샷과 별도 첨부 Blob을 하나의 트랜잭션에서 커밋한다. 각 워크스페이스 리비전으로 탭 간 충돌을 감지한다. |
| 데스크톱 영속성 | 원본은 UTF-8 Markdown과 별도 첨부 파일이다. 카탈로그는 식별자와 경로를 제공한다. 쓰기 준비 파일을 먼저 동기화하고 저널을 커밋한 뒤 원자 교체한다. 시작할 때 남은 저널을 재생한다. |
| 검색 | 두 플랫폼에서 로드된 Markdown으로 한국어 부분문자열 검색을 수행한다. Windows SQLite는 원본 체크섬과 복구 가능한 재색인 데이터를 보관한다. SQLite FTS5 검색 실행 경로는 차기 성능 개선 항목이다. |
| 문서명과 실제 파일명 | 새 파일은 정제된 제목에 ID 접미사를 붙인다. 제목 변경 시 파일명을 유지해 링크가 깨지는 경우를 줄인다. 문서·폴더 이동 시 알려진 상대 문서 링크를 재계산한다. |
| Markdown 편집 | Tiptap과 CodeMirror 6을 사용한다. 둘의 저장 기준은 하나의 Markdown 문자열이다. 시각적 편집기가 표현할 수 없는 일부 구문이 있는 문서는 원문 모드로 연결한다. |
| 첨부 | 모바일 카메라 입력과 파일 선택, 드롭, 붙여넣기를 제공한다. MIME은 파일 서명으로 확인한다. 사진은 기본적으로 원본을 보존한다. EXIF 제거를 켜면 변환한 파일만 저장한다. |
| 백업 | 프로젝트 ZIP에는 체크섬 목록과 상대경로 자산이 포함된다. 복원할 때 충돌 없는 ID를 발급하고 이미 같은 이름이 있으면 이름 뒤에 순번을 붙인다. |
| 출력 | 브라우저와 WebView2 인쇄 엔진을 사용한다. PDF 설정을 인쇄 CSS에 적용하며 브라우저나 Windows에서 사용자가 저장을 확정한다. |
| 정적 배포 | 한 SPA 주소에서 상태를 관리해 Pages 상세 경로 fallback 의존성을 없앤다. Web/PWA 번들은 서브경로를 반영한다. Windows 번들은 앱의 정적 자산을 직접 포함한다. |
| 브랜드·모션 | 1.1에서 Workspace 앱 전용 겹친 문서 모양을 헤더와 설치 아이콘에 적용한다. 회사 공식 심볼·워드마크 PNG는 바이트 그대로 패키징하며 설정 화면에 노출한다. Geist와 Geist Mono는 로컬로 번들링하고 한글은 운영체제 서체로 표시한다. UI 동작 및 저장 전환은 실제 상태와 모션 축소 환경설정에 연결한다. |
| 의존성 패치 | PWA 빌드 의존성의 간접 glob 범위를 npm overrides로 패치했다. API 호환성은 PWA 생성 및 오프라인 회귀 테스트로 확인한다. |
| 개발 범위 | V1은 단일 기기 저장과 수동 백업 이전을 지원한다. V1.5 템플릿·스냅샷·백링크, V2 동기화·계정, V3 전자결재·감사, V4 RAG는 별도 단계다. |
