# 제품 명세 오버레이 — v1.1

## 0. 변경 목적과 우선순위

2026-11-17 기존 개발명세(v1.0)에 **브랜드 디자인, Meta Astryx UI, 인터랙티브 모션, 비장식적 모션 그래픽** 요구를 추가한다. 기존 개발명세 본문은 변경 없이 유지한다. 본 문서는 추가·최신 결정을 정의하며 **기능명세에서 '디자인 제외'로 쓴 항목만 이 패키지의 디자인 문서로 보완**한다.

## 2. 비범위

- V1: 사내 문서 공개 웹 게시, 협업 실시간 공동 편집, 계정, 중앙 서버, S3 동기화, 접속 감사 원장, 결재 완료 불변성, AI RAG.
- GitHub Pages에 회사 문서 저장. `.env`에 비밀키를 넣은 채 정적 웹 빌드.
- 유료 모션 사이트의 효과/소스를 무허가 복제.

## 3. 권장 선택

- UI: `React 19`, `@astryxdesign/core`, 검증된 Astryx 테마, CSS 변수로 PRESTIQUE 오버라이드.
- 편집기: `Tiptap` + Markdown 변환기(지원 문법 명시), `CodeMirror 6` 원문 모드.
- Desktop: `Tauri 2`와 파일 시스템/SQLite 저장 어댑터.
- Browser: Vite 정적 앱, IndexedDB(문서/첨부), manifest/service worker 기반 PWA.
- Motion: CSS Transitions/Keyframes 우선; 추가 필요 시 `motion` 라이브러리를 선택적으로 평가. 모션 로직은 독립 계층.
- 브랜드 서체 원본은 이미지이지 폰트 파일이 아니다. 웹 본문 폰트는 보유·배포권이 확인된 서체만 채택한다.

## 4. 검증 필수 질문과 결정 기록

- 앱이 기준 폴더 외 임의 파일에 접근하지 않는가?
- 정적 배포물이 내부 문서/첨부·토큰·환경설정을 노출하지 않는가?
- 웹 오프라인 및 첨부 복구가 실제 단말기에서 동작하는가?
- 1MB 이상 이미지 여러 개 삽입해도 에디터 지연이 심하지 않은가?
- 밝은/어두운 테마에서 공식 어두운 워드마크가 충분히 보이는가? 필요시 **브랜드 원본은 바꾸지 말고 배경/보호 영역을 조정**.
- 작업 중 실패/저장완료 모션이 실제 상태를 정확히 표현하는가?
